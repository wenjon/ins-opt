🌿 天然 Natural

📌 全部用第一人称用户视角。核心："我"和水晶之间的故事——起点、挑选过程、意外的那颗、每天戴的、决定分享。只分享旅程和感受。

模板 A｜旅程起点型（最常用）

我以前不是 [水晶 / 戴首饰 / 关注这些] 的人。
[具体原因：觉得玄学 / 不感兴趣 / 觉得没必要]

然后 [具体事件：朋友送了一条 / 看到一条内容 / 经过一家店]
"试试看，" [对方] 说。
我当时 [不信 / 无所谓 / 当场拒绝]。

但 [最后 / 还是] [试了 / 戴了 / 看了]。

[一段时间后] 我 [没摘下来 / 离不开 / 想要更多]
现在我 [每天戴 / 入坑了 / 也在做]。

不是因为我变 [灵性 / 信仰] 了。
是因为手腕上有那么一个小小的东西
让我感觉 [是 / 像] 我自己。

这是我的水晶旅程，从 [起点] 到 [现在]。

模板 B｜我的挑选过程（不教识别）

朋友问："你怎么挑 [水晶 / 手链]？"

我不是 [专家 / 行家 / 老师]。
我 [不] [用什么工具 / 背什么图 / 有什么专业知识]。

我做的就是：

🌿 [动作 1：握在手里]
   [具体感受]
🌿 [动作 2：看一会儿]
   [具体感受]
🌿 [动作 3：看价格 / 来源]
   [具体感受]
🌿 [动作 4：找我信得过的人买]
   [具体说明]

就这样。[没专业知识 / 没用工具 / 全凭感觉]。
就是 [感觉 + 直觉 + 信任]。

如果你是新手：你不需要是专家。
你只需要 [开始 / 握一握 / 试一条]。

模板 C｜意外的那一颗（最有共鸣）

我买了一颗我没计划买的水晶。

[场景：在哪里 / 怎么遇到的]
不在我的清单上。
甚至不是我会 [喜欢 / 选] 的 [颜色 / 风格]。

但它有什么在叫我。我 [握了很久 / 看了一会儿]。
[对方] 注意到。"这颗 [一直在等你 / 适合你]，"[对方] 说。

我买了。带回家。
[具体过程：不知道放哪 / 试戴几天 / 慢慢习惯]

现在？这是我 [不知道戴什么时 / 不会出错时 / 出门随手抓] 的那条。
是我 [忘了还戴着 / 戴了一年 / 天天离不开] 的那条。

我不知道为什么它 work。
我就是知道。

你有没有 [买过"不是你"的东西 / 经历过"意外喜欢"]？

模板 D｜每天戴的那一条（最有习惯感）

有一条水晶，我天天戴。
戴了 [X 周 / 月 / 年] 了。

我不摘它：
🌅 [场景 1：早上]
💼 [场景 2：工作]
🛏️ [场景 3：休息]
✈️ [场景 4：旅行]
[场景 5：其他]

为什么是这条？
不是因为 [什么意义 / 书上说的 / 谁推荐的]。
就是因为 [它像我 / 大小对 / 颜色对皮肤 / 重量对]。

它不知不觉变成了我日常的一部分。

如果你还在找"你的那一条"——
继续 [试 / 戴 / 摸]。
你会知道什么时候"对了"。
