1.1 把 IG 账号转为 Business / Creator

  1. 打开 IG App
  2. 进入 Settings → Account → Switch to Professional Account
  3. 选择 Business 或 Creator
  4. 选择类目（推荐：Jewelry/Watches 或 Shopping & Retail）
  5. 关联一个 Facebook Page（如果还没有，先创建一个）

关联方法：Settings → Account → Linked Accounts → Facebook → Connect

1.2 注册 Meta 开发者账号

  1. 访问 developers.facebook.com
  2. 用你的 Facebook 账号登录
  3. 完成开发者注册（可能需要手机验证）

1.3 创建 Meta App

  1. 进入 developers.facebook.com/apps
  2. 点击 Create App
  3. 选择 Other → Next
  4. 类型选 Business
  5. 填写：
    - App name: Crystal IG Insights（或你喜欢的名字）
    - Contact email: 你的邮箱
  6. 创建完成后进入 App Dashboard

1.4 添加 Instagram Graph API 产品

  1. 在 App Dashboard 找到 Add a Product
  2. 找到 Instagram Graph API → 点击 Set Up
  3. 这样就启用了该 API 权限

1.5 申请必要权限

你需要这些权限（部分需要 App Review 审核）：

权限 用途 是否需要审核
instagram_basic 读取基本信息 ❌（个人开发者可用）
instagram_manage_insights 读取数据 insights ❌（个人账号可用）
pages_show_list 列出关联的 Pages ❌
pages_read_engagement 读取 Page 数据 ❌
business_management 商业管理 ⚠️（部分需审核）

个人账号的简化路径：如果你只是抓取自己的 IG Business 账号数据，大部分权限不需要 App Review，可以直接用。

1.6 获取 Access Token

步骤 A：用 Graph API Explorer 生成短期 Token

  1. 进入 Graph API Explorer
  2. 右上角 Meta App 选择你刚创建的 App
  3. User or Page 选择 User Token
  4. Permissions 添加：instagram_basic, instagram_manage_insights, pages_show_list, pages_read_engagement
  5. 点击 Generate Access Token
  6. 复制这个 short-lived token（1 小时过期）

步骤 B：换成长效 Token

打开浏览器（或用 curl）访问：

https://graph.instagram.com/access_token
  ?grant_type=ig_exchange_token
  &client_secret=你的APP_SECRET
  &access_token=刚才的短期TOKEN

APP_SECRET 在 App Dashboard → Settings → Basic → App Secret

返回的 JSON 里 access_token 字段就是 long-lived token（60 天有效）。

步骤 C：刷新长效 Token（防止过期）

60 天到期前，用这个 endpoint 刷新：

https://graph.instagram.com/refresh_access_token
  ?grant_type=ig_refresh_token
  &access_token=你的长效TOKEN

⚠️ 这个 endpoint 不会换新的长效 token，而是给一个新的 60 天 token。建议设置日历提醒每 50 天刷新一次。

1.7 获取 Instagram Business Account ID

用 Graph API Explorer（或浏览器）：

https://graph.facebook.com/v18.0/me/accounts?access_token=你的TOKEN

返回的 JSON 里找：
- id：Facebook Page ID
- instagram_business_account → id：Instagram Business Account ID（这才是你要的）

或者用：

https://graph.facebook.com/v18.0/你的PAGE_ID?fields=instagram_business_account&access_token=你的TOKEN

1.8 填入 .env

复制 .env.example 为 .env：

cp .env.example .env

用记事本打开 .env，填入：

IG_BUSINESS_ID=17841234567890123
IG_ACCESS_TOKEN=IGAAxxxx...长字符串
GRAPH_API_VERSION=v18.0
DATA_DIR=data
DEBUG=false

第二部分：自动化运行（Windows 任务计划程序）

2.1 测试脚本能正常运行

确保手动运行 run.bat 能成功。

2.2 打开任务计划程序

按 Win + R → 输入 taskschd.msc → 回车

2.3 创建基本任务

  1. 右侧点击 Create Basic Task...
  2. 名称：Crystal IG Weekly Fetch
  3. 描述：每周自动抓取 IG 数据

2.4 设置触发器

  • 触发频率：Weekly
  • 时间：每周日 22:00（你方便复盘的时间）
  • 勾选所有星期（每周日就行）

2.5 设置操作

  • 操作：Start a program
  • Program/script：D:\github\ins-opt\06-instagram-automation\run.bat
  • Start in：D:\github\ins-opt\06-instagram-automation

2.6 完成设置

  • 勾选 Open the Properties dialog → Finish
  • 在 Properties 里：
  • General tab: 勾选 Run whether user is logged on or not
  • Conditions tab: 取消 Start only if on AC power（笔记本用电池也要跑）

2.7 手动测试

  1. 在任务列表里找到 Crystal IG Weekly Fetch
  2. 右键 → Run
  3. 检查 data/ 目录是否有新 CSV 生成

2.8 监控任务是否成功

方法 A：查看历史

  • 任务计划程序 → 选中任务 → 看 Last Run Result
  • 0x0 = 成功
  • 0x1 = 失败

方法 B：看日志

  • 打开 Event Viewer（事件查看器）
  • Windows Logs → Application
  • 找来源为 "TaskScheduler" 的事件

方法 C：邮件通知

在任务的 General tab → 勾选 Send an e-mail when the task fails

需要先在 Action Center 配置 SMTP

第三部分：故障排查

Q1: 401 Unauthorized

原因：Access Token 过期或无效
解决：
1. 重新生成短期 token
2. 换成长效 token
3. 更新 .env 里的 IG_ACCESS_TOKEN

Q2: 400 Bad Request / "Invalid ID"

原因：IG_BUSINESS_ID 不正确
解决：
1. 用 https://graph.facebook.com/v18.0/me/accounts?access_token=TOKEN 查
2. 找到 instagram_business_account.id 字段
3. 更新 .env

Q3: 抓取不到数据（空白 CSV）

原因：
- 账号不是 Business 类型 → 转 Business
- 权限不足 → 检查 App 权限设置
- 账号刚转 Business，API 还没同步 → 等待 24 小时

Q4: Rate limit exceeded

原因：调用频率超限（每用户每 app 每小时 200 次）
解决：
- 减少抓取频率
- 本脚本每条帖子调用 2 次 API，25 条帖子 = 50+ 次调用，每周一次是安全的

Q5: 在中国运行，连接超时

原因：Graph API 域名（graph.facebook.com）在国内可能不稳定
解决：
- 在脚本里加 HTTP 代理
- 或在国内服务器 / 海外 VPS 上运行

修改 fetch_insights.py 的 api_get 函数：

proxies = {
    "http": "http://127.0.0.1:7890",  # 你的代理
    "https": "http://127.0.0.1:7890",
}
r = requests.get(url, params=params, timeout=30, proxies=proxies)

Q6: Python 没安装

解决：
- 下载 Python 3.11+
- 安装时勾选 Add Python to PATH
- 重启命令行

Q7: 依赖安装失败

解决：

python -m pip install --upgrade pip
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
