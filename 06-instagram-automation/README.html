快速说明

用 Instagram Graph API 自动抓取账号和帖子数据，保存到 CSV，方便复盘。

⚠️ 重要前提

这个功能需要你做一些前期准备：
1. 把 IG 账号转为 Business 或 Creator 账号（免费，5 分钟搞定）
2. 创建一个 Facebook Page（IG Business 账号必须关联一个）
3. 注册 Meta 开发者账号
4. 创建一个 Meta App
5. 申请 instagram_basic 和 instagram_manage_insights 权限
6. 获取长效 Access Token

完整流程见 scheduling-guide.md。

文件结构

06-instagram-automation/
├── README.md                       ← 本文件
├── fetch_insights.py               ← 主脚本
├── .env.example                    ← 配置模板
├── requirements.txt                ← Python 依赖
├── scheduling-guide.md             ← 完整配置 + 任务计划指南
├── data/                           ← 输出目录（自动创建）
│   └── .gitkeep
└── run.bat                         ← Windows 一键运行脚本

快速开始

1. 安装依赖

cd D:\github\ins-opt\06-instagram-automation
pip install -r requirements.txt

2. 配置环境变量

cp .env.example .env
# 用记事本编辑 .env，填入你的 IG_ACCESS_TOKEN 和 IG_BUSINESS_ID

3. 测试运行

python fetch_insights.py

成功的话会在 data/ 目录生成 CSV 文件。

4. 设置定时任务（可选）

按 scheduling-guide.md 配置 Windows 任务计划程序，每周自动运行。

抓取的内容

Account-Level（账号级）

  • 关注者总数
  • 触达（Reach）
  • 展示数（Impressions）
  • 主页访问
  • 链接点击
  • 周同比变化

Media-Level（帖子级）

最近 25 条帖子（API 限制）的：
- 发布时间
- 类型（IMAGE / VIDEO / CAROUSEL_ALBUM / REELS）
- 永久链接
- 文案
- 点赞 / 评论 / 收藏 / 分享
- 触达 / 展示

⚠️ 限制和注意事项

  • 只能抓 Business/Creator 账号，不能抓 Personal 账号
  • Access Token 60 天过期，需要定期刷新（脚本会提示）
  • 历史数据 API 限制：单次最多返回 25 条帖子，按时间倒序
  • Stories insights 单独接口，本脚本未涵盖
  • 不抓取粉丝个人信息（只抓聚合数据）

合规

  • ✅ 只使用 Meta 官方 Graph API
  • ✅ 不抓取其他用户数据
  • ✅ 遵守 Instagram Platform Policy
  • ❌ 不要把这个脚本用于抓取不属于自己的账号

备选方案

如果不想申请 Graph API：
- 手动方案：每周花 10 分钟看 IG Insights，手动填到 05-data-tracking/weekly-log.csv
- 第三方工具（收费）：Later、Hootsuite、Buffer 等都提供数据导出
- 截图方案：用 IG App 截图，每周存档（最简单）

故障排查

问题 解决方案
401 Unauthorized Access Token 过期，重新生成
400 Bad Request 检查 IG_BUSINESS_ID 是否正确
Permission denied App 权限未通过审核，重新申请
Rate limit 等待 1 小时后重试
Connection timeout 检查网络，必要时配置代理

详见 scheduling-guide.md。
