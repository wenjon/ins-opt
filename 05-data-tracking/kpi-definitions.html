KPI 定义

一级指标（每周必看）

1. Reach（触达人数）

含义：你的内容被展示给多少独立用户
怎么看：
- 越高越好，但变化率比绝对值重要
- 单条 Reels < 500 = 内容未破圈
- Feed 图文 < 200 = 受众定位可能偏

行动指引：
- 低 + 高 Saves = 优质但传播不够 → 投 promote
- 低 + 低 Saves = 内容问题 → 调整钩子

2. Saves（收藏数）

含义：用户主动保存你的内容
为什么重要：收藏 = 深度认可 = 购买意向最强信号

健康范围：
- < 5% Reach = 正常
- 5-10% Reach = 优秀
- > 10% Reach = 爆款潜力

行动指引：
- 高 Saves = 内容实用价值高 → 多做同类型
- 低 Saves = 看完就忘 → 增加"工具型"内容（清单、公式、教程）

3. Shares（分享数）

含义：用户把内容发给朋友或 Story
为什么重要：分享 = 自来水 = 病毒传播

健康范围：
- < 1% Reach = 偏低
- 1-3% Reach = 正常
- > 5% Reach = 爆款

行动指引：
- 高 Shares = 内容戳中痛点或社交货币 → 增加共鸣类
- 低 Shares = 内容自嗨 → 增加"@朋友"引导

4. Profile Visits（主页访问）

含义：看了内容后点进你主页的用户数
为什么重要：Bio 链接点击的前置

健康范围：
- 5-10% Reach = 正常
- > 15% Reach = 高意向

行动指引：
- 高访问低 Link Click = Bio 不够吸引 → 优化 Bio
- 高访问高 Click = 转化顺畅 → 加大此类内容

5. Link Clicks（链接点击）

含义：点击 Bio 链接或 Stories 链接贴纸
为什么重要：离转化最近的一步

健康范围：
- 1-3% Reach = 正常
- > 5% Reach = 优秀

6. DM Inquiries（私信询价）

含义：用户主动私信问价格、款式、发货
为什么重要：最终转化指标

行动指引：
- 高 DM + 高 Reach = 内容定位精准
- 低 DM + 高 Reach = 内容看热闹 → 加 CTA
- 高 DM + 低 Reach = 受众精准但传播不够 → 投 promote

二级指标（每月看）

Follower Growth（粉丝增长）

怎么看：
- 周增 < 50 = 增长慢
- 周增 50-200 = 正常
- 周增 > 500 = 快速增长

注意：粉丝数本身不重要，粉丝质量（互动率）更重要

Engagement Rate（互动率）

公式：(Likes + Comments + Saves + Shares) / Reach
健康范围：
- < 3% = 偏低
- 3-6% = 正常
- 6-10% = 优秀
- > 10% = 爆款

Follower Demographics（粉丝画像）

关注：
- 地域分布（MY 多少 / SG 多少）
- 年龄分布（18-24 vs 25-34）
- 性别比

行动指引：
- 地域集中 = 内容方向正确
- 年龄偏小 = 风格更年轻化
- 性别比失衡 = 调整内容角度

三级指标（看趋势）

Best Performing Post（最佳帖）

每月哪条表现最好？为什么好？

记录要素：
- 卖点
- 形式（Feed/Reels/Stories）
- 主题
- 发布时间
- 为什么成功（猜测）

Worst Performing Post（最差帖）

为什么差？下次如何避免？

Hashtag Performance（标签效果）

哪些标签带来的 Reach 最高？

关键比率（决策用）

Reach-to-Save Rate

Saves / Reach
→ 反映内容"工具价值"

Reach-to-Share Rate

Shares / Reach
→ 反映内容"社交价值"

Reach-to-DM Rate

DM Inquiries / Reach
→ 反映内容"转化价值"

⚠️ 红线指标

Unfollow Rate（取关率）

公式：单日取关数 / 粉丝总数
- < 0.5% = 正常
- 0.5-1% = 注意（内容偏离预期）
- > 1% = 警告（可能触雷或定位混乱）

Account Reach Health（账号健康度）

  • Reach 持续下降 2 周 = 警告
  • Reach 突然暴跌 = 可能被限流（检查是否违规）

与内容策略的连接

指标 对应内容动作
高 Saves + 低 Reach 内容好但传播不够 → 投 promote
高 Reach + 低 Saves 看完就忘 → 加"工具型"角度
高 Shares 共鸣强 → 增加"@朋友"引导
高 Profile Visits 想了解你 → 优化 Bio + Highlights
高 Link Click 行动意向强 → 加大此类内容
高 DM 转化意向强 → 准备接单话术

每周复盘 5 问

  1. 这周哪条 Saves 最高？为什么？
  2. 哪个卖点互动最好？
  3. 什么时间段发数据最好？
  4. 粉丝净增长多少？
  5. 下周需要调整什么？
